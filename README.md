# Exercício ES6

Bem-vindo ao repositório **Exercício ES6**! Este repositório contém exercícios práticos para aprender e praticar os recursos do JavaScript ES6. Aqui você encontrará exemplos e exercícios simples para ajudar a entender melhor as funcionalidades do ECMAScript 6.

## O que você vai encontrar aqui

- **Exemplos Práticos**: Código de exemplo para demonstrar os novos recursos do JavaScript ES6.
- **Exercícios**: Atividades práticas para reforçar o aprendizado.
